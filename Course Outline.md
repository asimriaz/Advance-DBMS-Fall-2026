### **Course Plan**
| | | |  
|-|-|-|  
| **Week** | **Topic** | **Detailed Topics** |   
| **1** | **Introduction to Advanced Database Systems** | Review of DBMS concepts; limitations of traditional databases; role of advanced database systems; overview of relational, distributed, NoSQL, graph and vector databases; real-world database applications. |   
| **2** | **Review of Relational Databases and Advanced SQL** | Relational model review; normalization; constraints; joins; sub-queries; views; indexes; basic query optimization concepts; introduction to PostgreSQL EXPLAIN. |   
| **3** | **Stored Procedures** | Purpose of stored procedures; PL/pgSQL syntax; variables; input/output parameters; conditional statements; loops; creating and calling stored procedures; simple business-rule examples. |   
| **4** | **Functions and Triggers** | User-defined functions; scalar and table-returning functions; trigger concepts; BEFORE and AFTER triggers; row-level triggers; validation and audit examples. |   
| **5** | **Cursors, Dynamic SQL and Views** | Cursor concept; declaring and fetching cursors; when cursors are useful; basic dynamic SQL; views; materialized views; differences between views and tables. |   
| **6** | **Transaction Management** | Transactions; ACID properties; COMMIT; ROLLBACK; SAVEPOINT; transaction states; concurrent transactions; common problems such as dirty reads and lost updates; isolation-level overview. |   
| **7** | **Concurrency Control** | Need for concurrency control; shared and exclusive locks; locking problems; deadlocks; deadlock prevention overview; optimistic vs pessimistic concurrency; introduction to PostgreSQL MVCC. |   
| **8** | **Database Recovery and Backup** | Database failures; backup and restore; transaction logs; checkpoints; undo and redo concepts; basic recovery process; PostgreSQL WAL overview; importance of disaster recovery. |   
| **9** | **Distributed Databases** | Distributed database concept; centralized vs distributed databases; advantages and disadvantages; horizontal and vertical fragmentation; data replication; distributed database architecture; practical examples. |   
| **10** | **Replication and Distributed Data Management** | Primary-replica concept; synchronous and asynchronous replication; read replicas; replication benefits; replication lag; consistency overview; introduction to database scalability. |   
| **11** | **NoSQL Databases** | Why NoSQL databases are used; relational vs NoSQL; key-value databases; document databases; column-family databases; basic MongoDB concepts; suitable use cases for each model. |   
| **12** | **Data Warehousing** | OLTP vs OLAP; concept of data warehouse; ETL process; fact and dimension tables; star schema; snowflake schema; data marts; basic analytical queries; simple warehouse example. |   
| **13** | **Graph Databases** | Graph database concept; nodes, relationships and properties; relational vs graph modeling; property graph model; basic Neo4j concepts; introductory Cypher queries; social network and recommendation examples. |   
| **14** | **Vector Databases and Semantic Search** | What vectors and embeddings represent; basic vector storage; similarity search; cosine similarity concept; PostgreSQL pgvector; semantic search; simple document-search example; introductory RAG concept. |   
| **15** | **Database Technology Selection and Case Study** | Comparison of relational, NoSQL, graph and vector databases; selecting the correct database for a problem; integrated case study; student project presentations; revision of major course concepts. |
